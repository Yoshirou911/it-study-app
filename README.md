# STACK — IT学習帳

基礎から応用まで、ITを体系的に学ぶための学習サイト。特定の資格試験の対策には閉じず、
コンピュータ科学の基礎からインフラ・設計・マネジメントまでを一続きのカリキュラムとして扱う。

## 特徴

- **教本 → 演習の流れ** — 分野ごとの解説(基礎/応用の2段階)を読んでから問題に取り組む構成
- **弱点克服型の出題** — 分野別の誤答率に応じて出題を重み付けし、苦手分野を重点的に出す
- **ランク表示** — 総合／分野別の理解度を S〜D のランクで可視化
- **科目B対応** — 擬似言語トレース問題(値を答える形式)
- **他の端末からも開ける** — 同じWi-Fi内のスマホ・タブレットから、QRコード(`/connect`)で開ける
- **アプリらしく開ける** — デスクトップのアイコンから、コンソールを表示せず専用ウィンドウで起動する

## 起動方法

デスクトップの **STACK** アイコンをダブルクリックするだけ。初回は仮想環境の構築とデータ投入が
自動で走り、完了すると専用ウィンドウでアプリが開く。終了するときは **STACKを終了** アイコンを使う。

手動で起動する場合:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python seed_db.py
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 問題・教本の追加方法

`data/seed/` 配下のJSONを編集し、`python seed_db.py` を実行する。

```
data/seed/questions_a.json   科目A(四択)
data/seed/questions_b.json   科目B(擬似言語トレース)
data/seed/notes/*.json       教本(分野グループごとに分割)
```

各項目は **`key`(固定キー)** を持つ。投入時はこのキーで既存レコードと照合し、

- キーが既にある → 内容を更新する(idは維持されるので**学習履歴はそのまま残る**)
- キーが無い → 新規追加する

という動作をする。そのため、問題文の修正も問題の追加も、学習履歴を失わずに行える。
DBを完全に作り直したいときだけ `python seed_db.py --reset` を使う(解答履歴も消える)。

> **注意**: 一度使ったキーは変更しないこと。変更すると別の問題として扱われ、
> それまでの解答履歴との紐づけが切れる。

キーの命名は `<分野スラッグ>-<連番>` で統一している(例: `nw-05`, `sec-12`)。
科目Bは `b-` を頭に付け(例: `b-algo-05`)、教本は `note-` を頭に付ける
(例: `note-basic-nw-05`)。新しい分野を追加した場合は `tools/assign_keys.py` の
`CATEGORY_SLUG` にスラッグを登録してから実行すると、キーのない項目にだけ自動で採番される。

## 開発

```bash
tools/make_icon.py      アプリアイコン(ico / PWA用png)を再生成する
tools/assign_keys.py    キーの無いシード項目に自動でキーを割り当てる
```

依存関係は `requirements.txt` に固定している。venvが壊れた場合は `.venv` フォルダごと
削除して、`start.bat` を再実行すれば作り直される。
